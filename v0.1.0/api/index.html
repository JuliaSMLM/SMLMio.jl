API

SMLMio — Module
SMLMio

File reading and writing for single-molecule localization microscopy (SMLM) data.

The emitters and cameras it reads and writes are SMLMCore's. The loaders return SMLMio's SmiteSMLD, an SMLMCore AbstractSMLD, and save_smite writes any SMLD of fit emitters. Positions are in µm, as in SMLMCore.

Formats

  • SMITE, the lab's MATLAB package: SmiteSMD names a .mat file, load_smite_2d and load_smite_3d read it into a SmiteSMLD, and save_smite writes one back. See SMITE files.

Example

using SMLMio

smd = SmiteSMD("path/to/data", "localizations.mat")
smld = load_smite_2d(smd)
mkpath("path/to/output")
save_smite(smld, "path/to/output", "copy.mat")

SMLMio.SmiteSMD — Type
SmiteSMD(filepath, filename, varname="SMD")

Name of an SMD variable in a SMITE .mat file: folder, file name and variable name.

Fields

  • filepath::String: folder holding the file.
  • filename::String: name of the .mat file.
  • varname::String: name of the SMD variable in the file.

Constructors

  • SmiteSMD(filepath, filename): the variable is "SMD", as SMITE names it.
  • SmiteSMD(filepath, filename, varname): a variable of another name.

Each argument can be any AbstractString; the fields are Strings.

Example

julia> SmiteSMD("path/to/data", "localizations.mat")
SmiteSMD:
  Filepath: "path/to/data"
  Filename: "localizations.mat"
  Variable name: "SMD"

SMLMio.SmiteSMLD — Type
SmiteSMLD{T,E<:AbstractEmitter} <: AbstractSMLD

SMLD of the fit emitters of a SMITE SMD; the SMD's other fields are kept in metadata.

Fields

  • emitters::Vector{E}: the localizations; positions and uncertainties in µm.
  • camera::AbstractCamera: an IdealCamera of XSize × YSize pixels of PixelSize µm, built from the file (an sCMOS calibration is not in the file).
  • n_frames::Int: frames per dataset (SMITE's NFrames); frame runs from 1 to n_frames in each dataset.
  • n_datasets::Int: number of datasets (SMITE's NDatasets).
  • metadata::Dict{String,Any}: the SMD's other fields and the loaders' entries; see SMITE files.

Constructors

Returned by load_smite_2d and load_smite_3d, with T = Float64. To build one, give both type parameters: SmiteSMLD{Float64,E}(emitters, camera, n_frames, n_datasets, metadata). save_smite takes any SMLD of fit emitters, so building one is rarely needed.

Reading

SMLMio.load_smite_2d — Function
load_smite_2d(smd::SmiteSMD; pixel_size=nothing) -> SmiteSMLD

Load a 2D SMITE SMD into a SmiteSMLD of Emitter2DFit{Float64}.

SMITE stores X, Y, X_SE and Y_SE in pixels, with (1, 1) the center of the top-left pixel. They load in µm from the camera's corner: x = (X - 0.5) * PixelSize, σ_x = X_SE * PixelSize. The camera is an IdealCamera of XSize by YSize pixels. How the loaders treat empty and per-dataset fields, and what is kept in the metadata, is on the SMITE files page.

Arguments

  • smd::SmiteSMD: the file and variable to load.

Keyword Arguments

  • pixel_size=nothing: µm per pixel, needed only when the file has no PixelSize (absent or empty); when the file has one, a different pixel_size is an error.

Returns

  • SmiteSMLD: the emitters in µm, with n_frames frames per dataset and the SMD's other fields in metadata.

Notes

  • Throws an ArgumentError when the file has no pixel size and none is passed, no image size (XSize, YSize; SMITE leaves them empty in a result without localizations), no NFrames or NDatasets or several of them, or a required field (X, Y, Photons, Bg, X_SE, Y_SE, FrameNum) without one value per localization; and when XSize, YSize, NFrames or NDatasets is not a whole number, or FrameNum, DatasetNum or ConnectID holds a value that is not (DatasetNum and ConnectID in the loaded rows).
  • Emitters with non-zero imaginary components are excluded with a warning.

Example

julia> using SMLMCore: IdealCamera, Emitter2DFit, BasicSMLD

julia> smld = BasicSMLD([Emitter2DFit{Float64}(1.0, 2.0, 1000.0, 10.0, 0.01, 0.01, 50.0, 2.0)], IdealCamera(64, 64, 0.1), 1, 1);

julia> dir = mktempdir(); save_smite(smld, dir, "localizations.mat")

julia> loaded = load_smite_2d(SmiteSMD(dir, "localizations.mat")); loaded.metadata["pixel_size"]
0.1

julia> e = loaded.emitters[1]; (e.x, e.y)
(1.0, 2.0)

SMLMio.load_smite_3d — Function
load_smite_3d(smd::SmiteSMD; pixel_size=nothing) -> SmiteSMLD

Load a 3D SMITE SMD into a SmiteSMLD of Emitter3DFit{Float64}.

Positions load as in load_smite_2d; Z and Z_SE are µm in SMITE and load unchanged. The file also needs Z and Z_SE with one value per localization. SMITE's SMD has no ZSize; when a file has one, it is appended to metadata["data_size"], and a ZSize that is not a whole number is an ArgumentError. Everything else (optional fields, metadata, pixel_size, the errors it throws) is as in load_smite_2d.

Arguments

  • smd::SmiteSMD: the file and variable to load.

Keyword Arguments

  • pixel_size=nothing: µm per pixel, needed only when the file has no PixelSize; when the file has one, a different pixel_size is an error.

Returns

  • SmiteSMLD: the emitters in µm.

Writing

SMLMio.save_smite — Function
save_smite(smld::AbstractSMLD, filepath::AbstractString, filename::AbstractString) -> nothing

Save an SMLD as an SMD variable in a SMITE .mat file (MATLAB v7.3), which the loaders read.

Positions convert from µm to SMITE's pixels, (1, 1) the center of the camera's top-left pixel: X = (x - x_edge) / pixel_size + 0.5 and X_SE = σ_x / pixel_size (the same for y), with x_edge the camera's first pixel edge. Z and Z_SE are µm in both. The file holds no SMF. Which fields are written, which are dropped and what a load gives back are on the SMITE files page.

Arguments

  • smld::AbstractSMLD: an SMLD (SmiteSMLD, BasicSMLD, or your own with emitters, camera, n_frames, n_datasets and metadata) whose emitters have x, y, photons, bg, σ_x, σ_y, σ_photons, σ_bg, frame, dataset and track_id, as Emitter2DFit and Emitter3DFit do (plus z and σ_z for 3D), and whose camera has pixel_edges_x and pixel_edges_y. Emitter2D and Emitter3D cannot be saved.
  • filepath::AbstractString: an existing folder.
  • filename::AbstractString: name of the .mat file; an existing file of that name is rewritten.

Returns

  • nothing.

Notes

  • The file is written in full to a temporary file before the target is touched, so a save that fails while writing leaves an existing file as it was; only an error during the final copy (a full disk, a lost share) can leave it partly written. What it refuses, and how a file is rewritten, are on the SMITE files page.

  • σ_xy, and in 3D σ_xz and σ_yz, are not saved: SMITE has no covariance fields, and they load as 0.

Example

julia> using SMLMCore: IdealCamera, Emitter2DFit, BasicSMLD

julia> smld = BasicSMLD([Emitter2DFit{Float64}(1.0, 2.0, 1000.0, 10.0, 0.01, 0.01, 50.0, 2.0)], IdealCamera(64, 64, 0.1), 1, 1);

julia> dir = mktempdir(); save_smite(smld, dir, "localizations.mat")

julia> e = load_smite_2d(SmiteSMD(dir, "localizations.mat")).emitters[1]; (e.x, e.y)
(1.0, 2.0)
